# Python Calculator

## Project Overview
Python Calculator is a beginner-friendly command-line calculator built with Python. It lets a user perform addition, subtraction, multiplication, and division.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Repeats the menu until the user chooses Exit
- Checks for invalid menu choices
- Handles non-numeric input
- Prevents division by zero

## Requirements
- Python 3
- Windows Command Prompt (CMD), or another terminal with Python installed

## How to Run
1. Save the program as `calculator.py`.
2. Open CMD in the project folder.
3. Run:

   ```bash
   python calculator.py
   ```

## Example
```text
===== Python Calculator =====

1. Addition
2. Subtraction
3. Multiplication
4. Division
5. Exit
Choose an operation (1-5): 1
Enter first number: 10
Enter second number: 5
Result: 15.0
```
