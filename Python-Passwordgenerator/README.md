# Python Password Generator

## 1. Project Overview
This project generates random passwords using Python. The user chooses the password length, and the program creates a password using letters, numbers, and symbols.

## 2. Objective
To learn how Python can generate random passwords and handle invalid user input.

## 3. Features
- Generates random passwords.
- Accepts the password length from the user.
- Requires a minimum length of 8 characters.
- Includes uppercase letters, lowercase letters, numbers, and symbols.
- Handles invalid input.

## 4. Tools Used
- Python 3
- Notepad
- Windows Command Prompt (CMD)

## 5. How to Run
Open CMD in the project folder and run:

```bash
python password_generator.py
```

## 6. Example Output

```text
===== Python Password Generator =====
Enter password length (minimum 8): 12
Generated password: [randomly generated password]
```

The actual password will vary each time.
